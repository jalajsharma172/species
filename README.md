# Spice Journey — Single Page Cinematic Landing

This repository contains a single-page cinematic storytelling landing site for a premium Indian spice brand.

Tech stack:
- Next.js + React
- Tailwind CSS
- GSAP ScrollTrigger
- Framer Motion
- Lenis for smooth scrolling
- Optional Three.js for particles

Quick start:

```bash
npm install
npm run dev
```
